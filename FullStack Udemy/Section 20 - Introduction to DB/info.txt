## SQL v/s No-SQL Database
-Use case based method will define which one is the best.
- SQL is best for use case where data is fixed and structure is known, also in this Architecture Vertically Scaling is allowed. 
- NoSQL is best for use case where data is dynamic and structure is unknown, and also the Architecture Scaling is Horizontal.
