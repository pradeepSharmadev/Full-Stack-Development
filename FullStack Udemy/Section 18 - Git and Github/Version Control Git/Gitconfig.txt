#Git Stash Analysis
- create a repo, work stage (add) and commit on main branch
- switch to another branch and work Note:- conflicting changes do not allow to switch branch, without commit,

- git stash
- git branch footer-bug-fix
- git checkout footer-bug-fix
- git stash pop  ===>(bring back those changes) stash can be move from on to other branch too.
- git stash list  ===> display the list of stash
- git stash apply stash{0}  ===>move to the mentioned stage list (apply them, and keep them in stash)
- git stash pop --> bring back changes from stash and apply it to current commit
